# 07-observability-stack — Observability Stack (Signals + Runbooks)

Stand up minimal observability locally and produce actionable alerts/runbook artifacts (local-first).

## Definition of Done

- steps.md completed with evidence artifacts saved
- verify.md contains concrete commands + expected signals
- cleanup.md proves resources/processes are removed
- runbook.md updated from real failures encountered
- resume-bullets.md and interview-explanation.md finalized
