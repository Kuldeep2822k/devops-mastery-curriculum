# Project 04: Security and Supply Chain

## Goal

Build an integration slice that feels like production work: reproducible, documented, and operable.

## Deliverables

- A working system (local-first) with a repeatable run
- A runbook (detection/diagnosis/mitigation)
- One ADR for a key tradeoff
- Evidence bundle (commands/outputs/screenshots where appropriate)

## Suggested Milestones

- M1: baseline working path
- M2: add safety gates and rollback
- M3: inject failure and recover (incident drill)
- M4: polish docs and self-grade
