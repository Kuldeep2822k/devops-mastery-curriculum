# Incident Communications Cheatsheet

## Update Template (External / Customer-Facing)

- What happened:
- Impact:
- Current status:
- What we’re doing:
- Next update time:

## Update Template (Internal / Engineering)

- Summary:
- Impact (SLO/user-facing):
- Timeline (key timestamps):
- Current hypotheses:
- Actions taken:
- What’s next (owners + ETAs):
- Risks/unknowns:

## Principles

- Prefer “what we know” over speculation.
- Time-box updates (e.g., every 15–30 minutes).
- Name a single incident commander (IC) and a single comms lead.
