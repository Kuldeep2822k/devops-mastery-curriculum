# Incident Log Template

## Quick Checks

- Confirm scope and recent changes
- Gather one confirming signal and one disconfirming signal
- Reduce blast radius before deep debugging

## Commands / Prompts

- write down hypothesis first
- run one command, interpret, then decide next check
