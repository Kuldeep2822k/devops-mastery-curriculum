# QA Audit Checklist

Use this to validate guide quality after edits.

## Structure

- Every module contains required files (overview, concepts, labs, checklist, review, troubleshooting).
- Every lab contains: Goal, Prereqs, Setup, Steps, Verify, Cleanup, Troubleshooting.

## Content Quality

- Verify sections contain concrete commands and expected signals.
- Examples do not include real secrets or unsafe practices.
- Cleanup sections prove resources/processes are stopped and artifacts removed.

## Navigation

- Indexes link to existing files.
- No broken relative links.
