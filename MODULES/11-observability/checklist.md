# Checklist — Module 11 Observability (DoD)

- [ ] Explain logs vs metrics vs traces with concrete examples.
- [ ] Demonstrate structured logging and avoidance of secrets in logs.
- [ ] Design 2 actionable alerts (availability + latency) with runbook links.
- [ ] Define an SLI/SLO and compute error budget conceptually.
- [ ] Design a dashboard outline with drill-down paths.
- [ ] Complete Lab 01 (instrumentation) and Lab 02 (alerts + runbooks drill).
- [ ] Complete at least 12 scenarios from [troubleshooting-lab.md](troubleshooting-lab.md).
- [ ] Complete [exam.md](exam.md) with evidence and reasoning.
- [ ] Write an observability runbook using [runbook-template.md](runbook-template.md).
- [ ] Write one ADR using [decision-record-template.md](decision-record-template.md) (alerting policy or SLO definition).
- [ ] Self-grade via [rubric.md](rubric.md) and list 3 improvement actions.
