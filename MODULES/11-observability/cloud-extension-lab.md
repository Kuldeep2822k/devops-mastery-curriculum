# Cloud Extension Lab (Optional) — Observability Stack

Core learning is local-first. This extension maps your signals to a real observability stack.

## Goal

Practice:

- centralized logs with retention
- metrics collection and alerting
- tracing and trace-to-logs correlation
- dashboards with release annotations

## Cost Control (Mandatory)

- set budgets and alerts before provisioning
- use free-tier plans where possible
- delete resources after verification

Read: [Lab Safety and Cost Control](../../00-HOW-TO-USE/03-lab-safety-cost-control.md)

## Verification Signals

- you can answer “what changed?” and “where is it failing?” in under 10 minutes using tools
- alerts include runbook links and are low-noise
- dashboards show version markers and key SLO posture

## Cleanup

- remove log retention and metrics resources if they incur cost
