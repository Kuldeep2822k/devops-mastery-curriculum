# Review Questions — Module 05 Containers

Answer from memory first.

1. Explain image vs container. What changes persist, and what do not?
2. What are image layers? How does Dockerfile order affect caching and build times?
3. Why are tags not reliable identity? Why are digests better?
4. What is the minimum evidence you capture before restarting/removing a container?
5. Explain why `localhost` is confusing in containers. Give two failure examples.
6. How do volumes change the data persistence story? What are common permission failure patterns?
7. What does exit code 137 usually indicate? What are common causes and mitigations?
8. Why might an app work locally on your host but fail inside a container?
9. What are secure defaults for container images and runtime?
10. Describe a strategy to keep production images minimal while retaining debuggability.
11. What are the top 5 docker commands you run in the first 5 minutes of an incident?
12. How do you design a smoke test for a container image?
