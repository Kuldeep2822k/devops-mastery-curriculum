# Checklist — Module 05 Containers (DoD)

- [ ] Explain image vs container and why container changes are not a deploy strategy.
- [ ] Explain tags vs digests and why promotion by digest matters for rollback and provenance.
- [ ] Build an image and run a container with port mapping and health verification.
- [ ] Demonstrate core ops commands:
  - [ ] `docker ps -a`, `docker logs`, `docker inspect`, `docker exec`, `docker stats`
- [ ] Complete Lab 01 with Verify + Cleanup evidence.
- [ ] Complete Lab 02 with at least 3 failure injections and evidence-based recovery.
- [ ] Complete at least 12 scenarios from [troubleshooting-lab.md](troubleshooting-lab.md) with written diagnosis and verification.
- [ ] Complete [exam.md](exam.md) with commands, expected signals, and reasoning.
- [ ] Write a container incident runbook using [runbook-template.md](runbook-template.md).
- [ ] Write one ADR using [decision-record-template.md](decision-record-template.md) (base image choice, debug strategy, tagging/digest policy).
- [ ] Self-grade via [rubric.md](rubric.md) and list 3 improvement actions.
