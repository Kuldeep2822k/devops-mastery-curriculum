# Checklist — Module 09 Config Mgmt (Ansible) (DoD)

- [ ] Explain idempotency and why it reduces incident risk.
- [ ] Build an inventory and demonstrate `--limit` use.
- [ ] Use variables with a clear structure (group_vars).
- [ ] Use templates and handlers appropriately.
- [ ] Demonstrate check mode and diff as a preview gate.
- [ ] Complete Lab 01 with evidence (second run no changes).
- [ ] Complete Lab 02 with evidence (drift detected in --check, then reconciled; serial rollout).
- [ ] Complete at least 12 scenarios from [troubleshooting-lab.md](troubleshooting-lab.md).
- [ ] Complete [exam.md](exam.md) with commands, expected signals, and reasoning.
- [ ] Write a runbook using [runbook-template.md](runbook-template.md).
- [ ] Write one ADR using [decision-record-template.md](decision-record-template.md) about rollout policy and secret handling.
- [ ] Self-grade via [rubric.md](rubric.md) and list 3 improvement actions.
