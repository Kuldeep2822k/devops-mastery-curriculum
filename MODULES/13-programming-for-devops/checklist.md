# Checklist — Module 13 Programming for DevOps (DoD)

- [ ] Build a CLI tool with safe defaults (dry-run) and bounded destructive actions.
- [ ] Use timeouts and retries with backoff for API calls.
- [ ] Handle pagination and max-items bounds.
- [ ] Emit structured output (JSON) for tooling integration.
- [ ] Avoid secrets in logs and stdout.
- [ ] Complete Lab 01 and Lab 02 with evidence.
- [ ] Complete at least 12 scenarios from [troubleshooting-lab.md](troubleshooting-lab.md).
- [ ] Complete [exam.md](exam.md) with evidence and reasoning.
- [ ] Write a runbook using [runbook-template.md](runbook-template.md) for “automation tool misbehaving”.
- [ ] Write one ADR using [decision-record-template.md](decision-record-template.md) about automation safety standards.
- [ ] Self-grade via [rubric.md](rubric.md) and list 3 improvement actions.
