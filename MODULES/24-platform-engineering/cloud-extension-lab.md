# Cloud Extension Lab — Module 24 Platform Engineering

This lab is optional. Run only after reading safety and cost control guidance.

## Goal

Map the local-first mental model to a single cloud provider and collect evidence.

## Safety

- Use a dedicated account/project and short-lived credentials.
- Set budgets/alerts and verify cleanup.

## Suggested Exercises

- deploy a minimal proof-of-concept using managed services
- run a failure drill (dependency down, rotation, rollback)
- capture costs and list optimizations
