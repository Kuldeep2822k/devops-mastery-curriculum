# System Design (DevOps) — Drills

Answer in: assumptions → design → failure modes → observability → rollback/safety → tradeoffs.

## Questions

- Design a deployment system for a multi-service product (rollback, promotion, auditability).
- Design an incident response workflow for a high-traffic API (roles, comms, evidence).
- Choose between queues vs streams for an event-driven system and justify tradeoffs.
- What are the top 5 failure modes you design for and how do you detect them?
