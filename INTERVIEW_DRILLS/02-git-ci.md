# Git + CI — Drills

Answer in: assumptions → constraints → approach → failure modes → verification → tradeoffs.

## Questions

- Explain your preferred branching + release strategy for a high-change repo and why.
- Walk through diagnosing a broken build where `dist/` is missing in CI but present locally.
- How do you design caches/artifacts so builds are fast but deterministic?
- Describe how you prevent secrets exposure in CI while still enabling deployments.
